# LatentWire

Enterprise AI news site with two surfaces:

- `index.html` — public homepage. Third-party AI news only. No Plexo units, no links to Reddit lead magnets.
- `articles/<slug>.html` — Reddit lead magnets. Each page carries personalized Plexo placements for a specific audience/subreddit.
- `styles.css`, `site.js`, `plexo-mark.png` — shared assets

Editorial and ad rules live in `/Users/Telmo/Plexo/news/_docs/STYLE-GUIDE.md` (kept out of the public repo).
